# supermarket-management-system

A full-stack supermarket management system with role-based access for Admin and Cashier users.

## Features

* Admin and Cashier authentication
* Role-based access control
* Product management
* Category management
* Inventory and stock management
* Point of Sale (POS) / billing
* Cart and discount handling
* Payment handling
* Sales history
* Dashboard and sales insights
* Form and frontend validation

## Technologies

* React
* TypeScript
* Vite
* Tailwind CSS
* Supabase
* JavaScript/TypeScript

## Project Setup

### Install dependencies

```bash
npm install
```

### Run the application

```bash
npm run dev
```

The application will then be available through the local Vite development server.
